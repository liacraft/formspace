
# formspace
A curated collection of UI/UX design, product design, and visual communication projects.

Built with HTML, Tailwind CSS, and Vanilla JavaScript, with no frontend framework or build tools required.

---

## Overview

formspace is a design portfolio showcasing selected projects, design explorations, and visual communication work across digital products and corporate environments.

It brings together detailed case studies and a visual gallery in a clean, responsive, and interactive experience.

The portfolio covers:

- UI/UX & Product Design
- Mobile & Web Applications
- Enterprise Digital Products
- Corporate Websites
- Visual Communication & Promotional Design
- Infographics & Digital Campaigns

---

## Features

### Project Showcase
- Dynamic project listing
- Category-based filtering
- Project detail views
- Previous and next project navigation
- Responsive project layouts

### Visual Design Gallery
- Masonry-style image gallery
- Category-based filtering
- Hover interactions with project information
- Image lightbox preview
- Responsive gallery layout
- Support for multiple visual assets

### UI/UX Case Studies

Selected projects can include:

- Project overview
- Role and responsibilities
- Tools and methods
- Design contributions
- Screens and mockups
- Interactive prototypes

## Purpose

formspace serves as a central space to present design work, document selected projects, and demonstrate an approach to creating thoughtful digital experiences and clear visual communication.

The goal is to balance usability, visual consistency, business needs, and attention to detail across different types of design projects.
